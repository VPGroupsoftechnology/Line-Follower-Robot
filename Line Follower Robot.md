# Line-Follower-Robot
A Line Follower Robot using Arduino Uno is a vehicle that follows a black line on a surface. IR sensors detect the line and send signals to the Arduino. The Arduino processes signals and controls motors through an L298N driver to move forward, left, or right. This project demonstrates automation, sensor interfacing, motor control, and robotics.

# Line Follower Robot

## Description
This project is an Arduino-based line follower robot.
The robot uses IR sensors to detect a black line and
automatically follows the path.

## Components
- Arduino UNO
- IR Sensor Module
- L298N Motor Driver
- DC Motors
- Robot Chassis
- Wheels
- Battery

## Features
- Automatic line following
- IR sensor based detection
- Two-wheel drive

## Software
- Arduino IDE
- C/C++

## How to Run
1. Open Line_Follower_Robot.ino in Arduino IDE.
2. Select Arduino UNO.
3. Connect the Arduino board.
4. Upload the program.
5. Place the robot on a line.
